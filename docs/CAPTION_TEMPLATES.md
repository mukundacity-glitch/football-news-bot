# Approved Future Caption Templates

Captions contain no URL or source line. Dynamic hashtags remove whitespace and accents.

## Transfer

```text
🚨 REPORTED TRANSFER: [PLAYER NAME]

[CURRENT CLUB] → [NEW CLUB]

STATUS: [REPORTED / COMPLETED / PENDING / OFFICIAL]

#TransferNews #[NEWCLUB] #[PLAYERNAME] #fpl
```

## Suspension

```text
⛔ SUSPENSION: [PLAYER NAME]

[CURRENT CLUB] | [REASON]

STATUS: [SUSPENDED / RETURNING / COMPLETED]

#FPL #FPLNews #[CLUB] #suspension
```

## Injury

```text
🚑 INJURY UPDATE: [PLAYER NAME]

[CURRENT CLUB]

INJURY: [INJURY]

STATUS: [OUT / DOUBTFUL / RETURNING / FIT]

#FPL #FPLNews #[CLUB] #Injury
```

## Press conference

```text
🎙️ PRESS CONFERENCE

[PLAYER / MANAGER]

[CLUB] | UPDATE: [KEY UPDATE]

STATUS: [CONFIRMED / REPORTED / EXPECTED]

#FPL #FPLNews #[CLUB]
```

All values come from verified facts. If a required availability or authority
status cannot be established, the post fails closed rather than inventing it.
